# Linux packaging

Builds `.rpm` and `.deb` packages with nFPM, and an Arch package from a PKGBUILD. Flatpak and AppImage aren't set
up yet.

Navia runs on Wayland only. Outside a Wayland session it says so and exits.

- `build-release.sh` builds in an Ubuntu 22.04 container, for glibc 2.35 and newer, and writes to
  `packaging/dist/<arch>/`. `--binary` or `--package` runs only one half. `--arch aarch64` cross-compiles
  for 64-bit ARM in the same container.
- `test-install.sh [x86_64|aarch64]` installs each package in clean Fedora, Arch, Debian and Ubuntu
  containers. aarch64 needs QEMU in binfmt_misc and skips Arch.
- `clean.sh` removes these containers, images and output by name. It never runs `docker prune`.

The app's name and ID are in `app.env`. The package and command are `navia`, and the app ID is
`com.davekai.Navia`. The desktop file, icons and metainfo are named after the app ID. The build stops if
`APP_ID` in `crates/navia-core/src/client/mod.rs` doesn't match. Desktops match the window's `app_id` to
`$APP_ID.desktop` to find its icon. The version comes from `apps/navia-gpui/Cargo.toml`.

`linux/icons/` has the app icon as SVG and PNGs for the hicolor theme, generated by `tools/brand_icons.py`.
`app-light.svg` isn't installed yet. If you add an icon size, add it to `linux/nfpm.yaml.in` too, or the build
fails.
